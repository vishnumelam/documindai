# DocuMind AI — Enterprise RAG Knowledge Assistant

Starter repository for the project described in `DocuMind_AI_Complete_Project_Documentation.pdf`.

## Planned stack
- React + TypeScript + Tailwind
- FastAPI + Python
- PostgreSQL
- Qdrant
- Ollama locally / hosted LLM in deployment
- Sentence Transformers embeddings
- BM25 + RRF + reranking
- Docker

## First milestone
PDF -> text extraction -> chunking -> local embeddings -> Qdrant -> retrieval -> Ollama -> cited answer.
